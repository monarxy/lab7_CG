# Лабораторная работа: OBJ, фигуры вращения и поверхности

Qt Widgets / C++11 / CMake. Проект основан на предыдущей лабораторной работе с многогранниками: сохранены классы `Point3D`, `Polygon`, `Polyhedron`, матрицы преобразований, проекции и виджет отрисовки.

## Сборка

Требуется Qt 5.12 или новее (модуль Widgets), CMake 3.16+ и компилятор C++11.

```bash
cmake -S . -B build
cmake --build build
```

Запуск:

```bash
./build/PolyhedraQt
```

В Windows исполняемый файл находится в `build/Debug` или `build/Release` в зависимости от генератора.

## Реализованные задания

### 1. Wavefront OBJ

Кнопки «Открыть OBJ» и «Сохранить OBJ» загружают и сохраняют текущую модель. Поддерживаются строки OBJ:

- `v x y z` — координата вершины;
- `f i j k ...` — грань, заданная индексами вершин.

Поддерживаются положительные и отрицательные индексы OBJ, а также стандартная запись грани с дополнительными полями (например, `f 1/1/1 2/2/2 3/3/3` — используются индексы вершин до первого `/`). Многоугольные грани сохраняются как многоугольники. Текстуры, материалы и нормали не импортируются, поскольку для задания достаточно геометрии вершин и граней.

### 2. Фигура вращения

В поле образующей указываются точки в формате `x, y, z`, по одной точке на строку. Затем выбираются ось X/Y/Z и количество угловых разбиений. Шаг угла равен `360° / N`. Между соседними точками образующей и соседними положениями образующей создаются четырёхугольные грани. Полученная модель становится текущей, поэтому её можно преобразовывать и сохранять в OBJ.

Пример образующей для цилиндра при вращении вокруг Z:

```text
1, 0, -1
1, 0, 1
```

### 3. Поверхность z = f(x, y)

Выбирается одна из функций:

- `x^2 + y^2`;
- `sin(x) * cos(y)`;
- `x * y`;
- `sin(sqrt(x^2 + y^2))`.

Задаются начало и конец одинакового диапазона для X и Y, а также число разбиений по каждой оси. Для `N` разбиений по каждой оси строится сетка `(N+1) × (N+1)` вершин и `N × N` четырёхугольных граней. Поверхность можно преобразовывать и сохранять в OBJ.

### Преобразования

Сохранены из предыдущей лабораторной: перенос, поворот вокруг X/Y/Z, масштабирование относительно центра модели, отражение относительно XY/XZ/YZ, поворот вокруг выбранной координатной оси через центр и поворот вокруг произвольной прямой через две точки.

## Примечания

- При открытии OBJ, построении фигуры вращения или поверхности текущая модель заменяется новой.
- Кнопка «Сбросить преобразования» возвращает выбранный правильный многогранник; после загрузки или генерации модели сброс возвращает куб.
- Для фигуры вращения программа строит боковую поверхность между соседними точками образующей; торцевые крышки автоматически не добавляются.
- Сетка поверхности состоит из четырёхугольных граней; отображение использует существующую сортировку граней по глубине из предыдущей лабораторной.
